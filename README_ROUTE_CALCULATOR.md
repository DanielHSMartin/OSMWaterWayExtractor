# Waterway Route Calculator

This script calculates optimal waterway routes between multiple waypoints using the graph data generated by `osm_waterway_extractor.py`.

## Features

- **Multipoint Routing**: Calculate routes through multiple waypoints in sequence
- **Smart Network Connection**: Automatically connects waypoints to the closest waterway edges
- **Disconnected Network Handling**: Uses straight-line connections when no waterway path exists
- **Comprehensive Debug Output**: Detailed logging of every calculation step
- **GeoJSON Output**: Industry-standard format for route visualization
- **Flutter-Compatible**: Uses only standard libraries that can be easily migrated to Dart/Flutter

## Usage

```bash
# Basic route between two points
python waterway_route_calculator.py nodes.json.gz edges.json.gz 52.5,13.4 52.52,13.42

# Multiple waypoints with output file
python waterway_route_calculator.py nodes.json.gz edges.json.gz 52.5,13.4 52.52,13.42 52.53,13.43 --output route.geojson

# Negative coordinates (use -- separator)
python waterway_route_calculator.py nodes.json.gz edges.json.gz -- -33.21,-57.21 -33.37,-57.68 --output route.geojson
```

## Input Format

- **Nodes file**: Gzipped JSON array of `[lat, lon]` coordinate pairs
- **Edges file**: Gzipped JSON array of edge objects with `start`, `end`, `length`, and `coordinates` fields
- **Waypoints**: Comma-separated lat,lon pairs (decimal degrees)

## Output Format

GeoJSON FeatureCollection containing:

- **Route LineString**: Complete route geometry through all waypoints
- **Waypoint Points**: Individual waypoint markers
- **Route Segments**: Individual segments between waypoints with detailed properties

## Algorithm Details

### 1. Edge Detection
- For each waypoint, finds the closest edge in the waterway network
- Uses efficient linear search through all edges (suitable for Flutter implementation)
- Calculates perpendicular distance to each edge geometry

### 2. Path Finding
- Uses Dijkstra's algorithm for optimal waterway paths
- Handles disconnected networks gracefully
- Tests all node combinations between start and end edges to find best route

### 3. Route Construction
- Connects waypoints to network with straight lines when needed
- Assembles complete route geometry from edge coordinates
- Preserves coordinate precision from original data

### 4. Debug Information
- Logs every step of the calculation process
- Reports distances, edge IDs, and node paths
- Provides timing and performance metrics

## Libraries Used

All libraries have direct Dart equivalents for Flutter migration:

- `json` → `dart:convert`
- `gzip` → `dart:io` compression
